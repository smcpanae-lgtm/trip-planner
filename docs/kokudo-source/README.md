# 国道パスポート 路線データの取得元

国道パスポート（一般国道459路線の記録アプリ）に使う路線データ（路線番号・起点・終点・
通過都道府県）は、以下の2つの公開資料から取得し、転記して作成しました。
AIの記憶からは一切書いていません。

## 取得した資料

1. **主資料**：全国国道路線一覧表
   - URL: https://fukatsuyasuna.sakura.ne.jp/nh-list-zenkoku.html
   - 取得日時: 2026-08-25 23:11 (JST)
   - 保存ファイル:
     - `fukatsuyasuna-nh-list-zenkoku.html`（取得した生データ。Shift_JIS）
     - `fukatsuyasuna-nh-list-zenkoku.utf8.html`（UTF-8に変換したもの。パース処理はこちらを使用）
   - 路線番号・起点・終点・通過都道府県・備考の5列を持つ表が6個あり、全459路線を含む。

2. **副資料（突き合わせ用）**：Wikipedia「日本の一般国道一覧」
   - URL: https://ja.wikipedia.org/wiki/日本の一般国道一覧
   - 取得日時: 2026-08-25 23:12 (JST)
   - 保存ファイル: `wikipedia-nihon-no-ippan-kokudo-ichiran.html`
   - 路線番号・起点・終点・総延長などを持つ表。通過都道府県の列はないため、
     起点・終点の都道府県が主資料と一致するかの突き合わせにのみ使用。

## 処理の流れ（再現可能なスクリプト）

1. `parse_primary.py` … 主資料のHTML表をパースし `parsed-primary.json` を生成。
2. `parse_wikipedia.py` … 副資料のHTML表（MediaWikiのテンプレートパラメータ）をパースし
   `parsed-wikipedia.json` を生成。
3. `build_and_check.py` … 上記2つを突き合わせ、機械チェックを行い、
   `kokudo-routes-check.csv`（確認用一覧）、`built-records.json`（全459路線の構造化データ）、
   `review-list.json`（要確認フラグが立った路線のみ）を出力。

いずれのスクリプトも `python3 <ファイル名>` で再実行できます（インターネット接続不要。
既に取得済みのHTMLファイルのみを読みます）。

- 通過都道府県が0件の路線: なし

## 転記時に判断・正規化した点（自己判断で「直した」のではなく、根拠を明記した処理）

- **重複する通過都道府県の一意化**（No.3, No.16）: 資料に同じ都道府県が2回書かれている
  （ループ状の経路のため）。アプリのデータ構造は「路線×都道府県」の組で1レコードなので、
  重複を除いた順序維持リストを `throughPrefs` として使用。元の記載は `throughPrefsSource` /
  `throughPrefsRaw` に保持。
- **括弧表記の正規化**（No.499のみ）: 資料が「（熊本県）」と括弧付きで記載（陸上区間はないが
  海上区間で通過するとみなす、という資料自身の備考による注記）。これを正規の都道府県名
  「熊本県」に正規化。元の表記は `throughPrefsSource` に保持。他の458路線にはこの表記は
  現れないことを機械チェックで確認済み。
- **起点/終点セルの1行連結の分割**（No.165のみ）: 資料側でこのセルだけ空行が欠落しており
  「三重県津市」が1行で連結されていた。既知の47都道府県名との前方一致で「三重県」+「津市」
  に分割（データの追加・推測ではなく、既存の文字列を正しく分割しただけ）。

## ユーザー確認済みの補正（No.8, No.14, No.173, No.289）

主資料の「終点」欄の都道府県名が、同じ欄の市区町村名・備考欄の記述・副資料（Wikipedia）の
いずれとも食い違っている4路線を発見した（例: No.14は「終点：東京都 千葉市中央区」だが
千葉市は千葉県）。通過都道府県のリスト自体は正しく、「終点の都道府県」という表示項目1つに
限った資料側の入力ミスと判断できたため、ユーザーに報告して確認を取り、裏付けが取れた
都道府県名に補正した（自己判断での無断修正ではない）。元の（誤っている）表記は
`toPrefSource` フィールドに保持し、補正理由は `reviewReasons` に記録している。
