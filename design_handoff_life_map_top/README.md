# Handoff: 人生体験マップ（life-map）トップページ再デザイン

## Overview
既存サービス「人生体験マップ」(`/life-map`, https://www.ai-drive-planner.com/life-map) のトップページ再デザイン。
写真と場所で人生の体験（旅行・釣り・食事・犬連れ 等）を**端末内（ローカルストレージ）にのみ**記録する非公開ライフログ。
本パッケージは、ヘッダー／ヒーロー／記録UI／地図／タイムライン／注意事項までを含む1ページ完結のデザインです。
ヒーローは **2案（ティール強め / アンバー強め）** を用意しています。

## About the Design Files
このバンドル内の `.dc.html` は **HTMLで作成したデザインリファレンス**（見た目と挙動を示すプロトタイプ）であり、そのまま本番に貼り付けるコードではありません。
既存の `/life-map` は **Next.js / React + Tailwind CSS** で実装されています。タスクは、これらのデザインを**既存コードベースの技術・パターン（React コンポーネント、Tailwind、既存の状態管理・localStorage 層）で再現**することです。新規に別フレームワークを起こす必要はありません。

> `.dc.html` は社内デザインツール形式です。中身は通常のHTML＋インラインスタイルなので、ブラウザで開けば見た目を確認できます。ロジックは末尾の `<script data-dc-script>` 内 `class Component`（React クラス相当）にあります。

## Fidelity
**High-fidelity (hifi)。** 色・タイポグラフィ・余白・角丸・影・アイコンは最終指定に近い値です。既存の Tailwind / コンポーネントでピクセルに近い再現をしてください。
※地図パネルとサムネイル写真は**見た目のプレースホルダー**です（後述）。

---

## 重要な制約（既存挙動の維持）
- **localStorage 連携のJS、ボタン・フォームの id / class 名は一切変更しない。** 本デザインの各コントロールに、既存のハンドラ・data属性・id/classをそのまま割り当ててください。
- life-map は React 実装のため固定 id はほぼ無く、コントロールは Tailwind クラスで表現されています。**本デザインはあくまで見た目の指定**であり、配線（onClick、input の accept、localStorage 読み書き、地図初期化）は既存実装を流用してください。
- **注意事項アコーディオンの文面は既存サイトのまま**（改変禁止）。原文の先頭にあった絵文字 📋 / 💾 のみ線画アイコンへ置換していますが、**本文テキストは1文字も変えていません**。

## Interactions & Behavior
- **ナビ / CTA**: アンカー（`#howto` `#faq` `#record`）とページ遷移（`/shiori`, `/heritage`）。既存ルーティングに合わせる。
- **表示切替（時系列/地域別）**: `view` state（`'timeline' | 'region'`）で切替。アクティブボタンは白背景＋影、非アクティブは透明背景＋`#8A8172`。**既存の一覧描画ロジックに接続。**
- **並び替え（新しい順/古い順）**: 本デザインでは静的。既存のソート状態に接続。
- **アコーディオン**: native `<details>`。開いた時 chevron を 180° 回転（`details[open] .acc-chev { transform: rotate(180deg) }`, transition `.2s`）。
- **記録ボタン群**: 見た目のみ。既存の file input（`accept="image/*"`）、カメラ起動、複数選択、バックアップ書き出し/読み込み（JSON, 自動マージ）ハンドラを割り当てる。
- **レスポンシブ**: デザインは1080px幅基準。実装ではモバイルで2カラム→1カラム（ヒーロー→記録→地図→一覧）へ、ヘッダーは既存のレスポンシブ挙動に合わせる。

## State Management
- `heroTheme`: `'teal' | 'amber'`（採用案の選択。最終的に片方へ確定）
- `view`: `'timeline' | 'region'`（一覧の表示モード）
- `sort`: `'new' | 'old'`（並び替え）
- `showPassportLink` / `showJournalBanner`: 表示トグル（任意）
- 記録データ・写真・年齢等は**既存の localStorage 層をそのまま利用**（本デザインは触れない）。
